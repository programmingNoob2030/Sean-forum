## 4.4 Indexed / Fine：索引优化后的细粒度测试

根据 Indexed / Coarse 测试结果，COMMENTS 排序接口在 70～80 threads 区间出现明显的性能退化，因此进一步以 2 threads 为步长进行细粒度测试。

### 测试结果

| Threads | Requests | Success | Avg    | Min   | Max    | P95    | P95 涨幅 |
| ------- | -------- | ------- | ------ | ----- | ------ | ------ | -------- |
| 70      | 700      | 100%    | 64 ms  | 24 ms | 133 ms | 91 ms  | —        |
| 72      | 720      | 100%    | 172 ms | 26 ms | 742 ms | 278 ms | +205.49% |
| 74      | 740      | 100%    | 78 ms  | 26 ms | 253 ms | 137 ms | -50.72%  |
| 76      | 760      | 100%    | 96 ms  | 26 ms | 311 ms | 170 ms | +24.09%  |
| 78      | 780      | 100%    | 126 ms | 25 ms | 397 ms | 224 ms | +31.76%  |
| 80      | 800      | 100%    | 215 ms | 28 ms | 849 ms | 440 ms | +96.43%  |

### 测试分析

从测试结果来看，70 threads 时 P95 为 91 ms，而 72 threads 时迅速上升至 278 ms，较上一档增长 205.49%，之后整体维持在较高延迟区间，并在 78～80 threads 进一步升高。

其中 74 threads 的 P95 回落至 137 ms，说明该区间存在一定的测试波动，因此不能仅依据单次测试结果确定一个绝对精确的性能拐点。

为验证该现象，对 70～80 threads 区间进行了额外复测。复测结果中，72 threads 的 P95 再次达到 240 ms，进一步说明 72 threads 附近出现的明显延迟增长并非单次测试的偶然现象；同时，不同测试之间的具体 P95 数值仍存在一定波动。

因此，本轮测试将 **约 72 threads** 作为 COMMENTS 排序接口进入明显性能退化区间的参考位置，而不将其视为绝对精确的并发阈值。
